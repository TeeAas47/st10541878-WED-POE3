### Project Overview
Responsive e-commerce website for Choppies Supermarket, Bloedrivier Limpopo. Part 3 adds JavaScript interactivity.

### Part 3 - New Features (JavaScript)
- **Search/Filter:** Live product search on products.html
- **Lightbox Gallery:** Click product image to enlarge with lightbox
- **Form Validation:** Custom JavaScript validation on enquiry.html (name, email, type, message) with red error messages and green success
- **SEO:** Added meta description tags, sitemap.xml, robots.txt

### Website Pages
- index.html - Home
- pages/about.html - About Choppies
- pages/products.html - Products with search + lightbox
- pages/enquiry.html - Enquiry form with validation
- pages/contact.html - Contact details + map
